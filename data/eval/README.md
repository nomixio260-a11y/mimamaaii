# 評価セットの書式

TSV、1 行 1 ステップ。列:

| 列 | 内容 |
|---|---|
| 1 | 質問 (会話の順番どおりに実行される。`@reset` で会話状態をリセット) |
| 2 | 期待条件。`|` 区切りの語のいずれかが答えに含まれれば正解。`!語` はその語を含んではいけない。`~正規表現` は正規表現一致。`mode:fact,recall` は応答モードの期待。`conf<0.5` / `conf>=0.4` は確信度の条件。空なら「正直に知らないと言う」ことを期待 (conf<0.3) |
| 3 | 事前に学習させる文 (省略可、`\n` で複数行) |
| 4 | カテゴリ (省略時はファイル名) |

`#` で始まる行はコメント。言い換え (`〜とは？` `〜って何？` `〜を教えて` `〜は？`) は `tools/eval.py --paraphrase` で自動生成して同じ答えを期待する。
